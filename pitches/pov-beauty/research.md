## Company Overview

POV Beauty is a skin-prep-focused D2C beauty brand co-founded by:
- **Mikayla Nogueira** — beauty creator with ~21M followers across TikTok + Instagram, former Ulta Beauty advisor
- **Ani Hadjinian** — beauty industry veteran, former GM North America at Augustinus Bader

Launched March 26, 2025. Sold out in <24 hours ($1M in 8 minutes). Backed pre-launch by Imaginary Ventures (Alix Earle's Reale Actives, etc.).

## Proprietary Technology Claims (from /pages/formulate-it)

1. **Snatch It Technology™** — PDRN + peptides + ceramides for firm/lift/plump
2. **2x FermentVitalComplex™** — 2-step fermented ginseng/potato/adlay/rice/soybean for soothe/brighten
3. **Megamirrored Molecular Complex™** — panthenol + niacinamide + HA Complex for vibrancy/barrier
4. **Barrierbolster Technology™** — ectoin + shea butter + glycerin for barrier/hydration
5. **Gripping Glaze Technology™** — niacinamide + glycerin + polymers for adherence/glass-skin
6. **Elastin Glow Technology™** — triple butter/argan/HA spheres for lip restoration

Each tech maps to specific products (detailed on formulate-it page).

## Identified Gaps (candidate list for Phase 2)

1. **No developer documentation** for mobile app API, retail integrations (Sephora EDI, TikTok Shop), or partner onboarding
2. **Proprietary technology claims** (6 trademarked complexes) lack technical white papers / specification docs — IP defensibility risk
3. **Multi-channel ops scaling** — Sephora + TikTok Shop + DTC + Subscriptions = complex integration web with no visible docs
4. **Mobile app "My POV"** — community features (tips, challenges, rewards) imply backend API with no public docs
5. **No engineering hiring** — technical debt accumulating; agency handoffs without documentation
6. **Investor pressure for durability** — "enterprise with executive backbone" requires documented technical foundation
